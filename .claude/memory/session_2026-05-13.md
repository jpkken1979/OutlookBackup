## Decisiones tecnicas tomadas en la sesion

1. **path_utils conservador**: solo agrega prefijo \\?\\ si len > 240 chars. Passthrough
   para paths cortos preserva compat con APIs viejas.
2. **WebView2 bundling**: bootstrapper evergreen ~1.7MB en Inno Setup (no offline standalone
   de 150MB). Decision aprobada explicita por el usuario.
3. **Feature C post-process vs Items.Restrict()**: opte por backup full + delete fuera del rango
   por simplicidad. Items.Restrict() requiere refactor del COM loop + extender FakeOutlookClient.
   Optimizar en futura iteracion.
4. **Feature C sin UI todavia**: backend implementado, UI deferred a sesion dedicada (1h budget no
   alcanzaba para ambos bien hechos).
