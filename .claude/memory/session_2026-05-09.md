## Descubrimientos
- El frontend usa polling con setInterval cada 500ms (no callbacks ni async/await)
- App singleton en app.js tiene metodos dedicados: startBackupPolling, startImportPolling, startCacheBackupPolling
- Progress overlay es compartido entre backup, import y cache_backup
- Credential Vault filtra por OUTLOOK_PATTERNS hardcodeados
- Registry busca en 3 versiones de Office (16.0, 15.0, 14.0)
- Win32 fallback con WIN32_AVAILABLE en todos los modulos que usan pywin32
