# Dev Server Reference — Start Commands by Framework

Generic reference for common framework dev server start commands and default ports.

## Rails

```bash
bundle exec rails server
# Default port: 3000
```

## Next.js

```bash
npm run dev
# Default port: 3000
```

## Vite

```bash
npm run dev
# Default port: 5173
```

## Nuxt

```bash
npm run dev
# Default port: 3000
```

## Astro

```bash
npm run dev
# Default port: 4321
```

## Remix

```bash
npm run dev
# Default port: 3000
```

## SvelteKit

```bash
npm run dev
# Default port: 5173
```

## Procfile-based (Rails/other)

```bash
heroku local
# or
foreman start
```
