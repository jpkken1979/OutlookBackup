# Beautiful Prose

A style contract that strips AI tics and weak language to produce prose that reads like it was written by a serious writer, not generated by a model.

## The Core Rules

### 1. Eliminate Filler Words (Forbidden List)

Replace these weak words immediately:

| Weak | Strong | Example |
|------|--------|---------|
| leverage | use | "We **use** data..." (not "leverage data") |
| utilize | use | "They **use** Python..." (not "utilize") |
| delve into | explore / examine | "Let's **examine** this..." (not "delve into") |
| robust | strong / reliable | "A **reliable** system..." (not "robust") |
| seamless | smooth / frictionless | "A **smooth** experience..." |
| cutting-edge | latest / new | "The **latest** technology..." |
| synergy | combination / together | "Working **together**..." |
| paradigm shift | change / transformation | "A **fundamental change**..." |
| deep dive | analysis / detailed look | "Our **analysis** shows..." |
| stakeholder | user / customer / person | "What do **customers** want..." |
| best practice | standard / method | "The **standard** approach..." |

### 2. Enforce Active Voice

**Passive**: "The data was analyzed by researchers."
**Active**: "Researchers analyzed the data."

**Rule**: The actor should come before the verb. If you can't name the actor, rethink the sentence.

### 3. Short Sentences

**Long (weak)**: "The implementation of the new system, which required considerable investment and coordination across multiple teams, has fundamentally improved operational efficiency."

**Short (strong)**:
- "The new system required major investment.
- We coordinated across three teams.
- Operational efficiency improved 40%."

**Target**: Average 12-15 words per sentence. Maximum 25 words. (This paragraph: 11 avg, max 17.)

### 4. Strong Verbs

Replace weak verb + adverb combos with a single strong verb:

| Weak | Strong |
|------|--------|
| is important | matters / drives / enables |
| has the ability to | can |
| makes it possible to | enables |
| is a significant problem | harms / threatens / undermines |
| tend to | often / usually |
| appear to | seem / look |

### 5. Eliminate Hedging

**Hedged**: "It might be argued that this could potentially suggest..."
**Direct**: "This suggests..."

**Rule**: Own your claims. If you're uncertain, say so directly. Don't hide behind modal verbs.

## Pre-Writing Checklist

Before drafting, ask yourself:
- [ ] Is this for humans or machines? (If human, use Beautiful Prose)
- [ ] Can I read this aloud without sounding robotic?
- [ ] Does every sentence earn its place?
- [ ] Am I hedging when I should be direct?
- [ ] Have I named the actor in each sentence?

## Revision Checklist

Work through these in order:

1. **Filler check**: Find and replace weak words (use Find feature)
2. **Voice check**: Highlight any "is/are/was/were" + past participle (passives)
3. **Length check**: Sentences > 25 words? Break them.
4. **Verb check**: Replace "is [adjective]" with strong verb
5. **Hedge check**: Look for "might, could, seem, appear, tend" — justify each one
6. **Read aloud**: Does it sound like a real person? If not, rewrite.

## Common AI Tics to Eliminate

These give away AI-generated text:

| Tic | Why | Fix |
|-----|-----|-----|
| "In today's world" | Temporal filler | Delete it |
| "It's important to note that" | Obvious statement | Delete it |
| "At the end of the day" | Cliché | Delete it |
| "In conclusion" | Signal, not substance | Delete it |
| "Take for example" | Weak setup | "Consider:" or just start the example |
| Series of rhetorical questions | Artificial pacing | Make one claim instead |

## Style Examples

### Technical Writing

**Before**: "The implementation of the microservices architecture enables the seamless integration of multiple independent services, which facilitates the scaling of individual components."

**After**: "Microservices scale independently. Each service integrates separately. This makes the system more flexible."

### Marketing Copy

**Before**: "Our cutting-edge platform leverages advanced AI to provide users with unparalleled insights."

**After**: "Our platform runs AI analysis on your data. You get insights competitors miss."

### Documentation

**Before**: "Users should be aware that the configuration process requires modifications to environment variables in order to properly initialize the system."

**After**: "To start the system, set these environment variables."
