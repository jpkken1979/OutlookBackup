# Skill: Nexus Agent Debate
> Orquestacion avanzada por consenso de multiples agentes.

## Descripcion
Inicia un debate entre el Supervisor, Arquitecto, Auditor y Especialista para resolver problemas complejos por consenso.

## Uso
`python scripts/agent_debate.py \"<tarea_descripcion>\"`

## Cuando usar
Usa esta skill para decisiones criticas de arquitectura o seguridad donde una sola opinion de IA no sea suficiente.
