# Skill: Nexus Skill Miner
> Mineria automatica de conocimiento de codigo.

## Descripcion
Escanea un directorio en busca de funciones Python documentadas y las convierte en archivos de Skill .md para el catalogo de Antigravity.

## Uso
`python scripts/skill_miner.py <target_dir>`

## Cuando usar
Usa esta skill cuando inyectes una app nueva para \"absorber\" sus funciones y que Nexus aprenda de ellas automaticamente.
