# Skill: Nexus Shadow Workspace
> Validacion segura de cambios en un entorno Sandbox (Shadow).

## Descripcion
Crea una copia temporal del proyecto, aplica los cambios propuestos y corre los tests antes de tocar el repositorio real.

## Uso
`python scripts/shadow_workspace.py`

## Cuando usar
Usa esta skill antes de aplicar refactors masivos o cambios que puedan romper el build para asegurar un 100% de confianza.
