# Skill: Nexus Token Warden
> Optimizacion de costos y seleccion inteligente de modelos LLM.

## Descripcion
Analiza la complejidad de una tarea y recomienda el modelo mas eficiente (Ollama, Claude, GPT) para ahorrar tokens y tiempo.

## Uso
`python scripts/token_warden.py \"<tarea_descripcion>\"`

## Cuando usar
Usa esta skill al inicio de tareas complejas o masivas para decidir que modelo disparar sin gastar de mas.
