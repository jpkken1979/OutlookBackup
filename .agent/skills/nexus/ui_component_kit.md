# Skill: Nexus Component Kit (Pro Max)
> Biblioteca de UI Premium para el ecosistema Antigravity.

## Descripcion
Suite de componentes React estilizados con Stitches y Tailwind v4, diseñados para interfaces de alta gama.

## Componentes Disponibles
- **GlassCard**: Contenedor principal con Glassmorphism y Glow.
- **GlowButton**: Botones con aura y micro-interacciones.
- **StatusOrb**: Indicadores de salud de agente animados.
- **NexusInput**: Inputs de alta fidelidad con efectos de foco.
- **AgentAvatar**: Iconos de identidad de agentes por color.
- **DataList**: Listas de telemetría de alto contraste.

## Reglas de Implementacion
1. Importar desde: `@/components/nexus-ui`.
2. Seguir siempre la jerarquia visual de `DESIGN_SYSTEM.md`.
3. Usar `GlassCard` para cualquier contenedor de informacion relevante.
4. Mantener la paleta de colores Dark (#0a0a0c) con acentos Indigo (#6366f1).
