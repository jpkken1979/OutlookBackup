# Skill: Nexus Self-Healing
> Auditoria y reparacion automatica de ecosistemas inyectados.

## Descripcion
Detecta derivas (drift) en los archivos de Antigravity inyectados y aplica reparaciones usando el mcp_injector.

## Uso
`python scripts/nexus_self_healing.py <target_dir>`

## Cuando usar
Usa esta skill cuando sospeches que una app inyectada no esta funcionando bien o si faltan archivos de reglas/hooks.
