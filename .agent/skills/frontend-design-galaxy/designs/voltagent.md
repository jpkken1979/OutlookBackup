## Vibe

Void-black agent interface with emerald charge, terminal confidence, and futuristic restraint.

## Best For

- agentic dashboards
- automation panels
- terminal-adjacent tooling

## Palette Notes

Use black and deep graphite with emerald accents, keeping contrast high and ornament low.

## Typography Notes

Use clean sans UI type with selective monospace for commands, logs, and metrics.

## Layout Notes

Favor modular panels, operational density, and surfaces that feel like control infrastructure.

## Component Notes

Status chips, consoles, cards, and quick-action bars should feel active, precise, and machine-ready.

## Remote Excerpt

AI agent framework. Void-black canvas, emerald accent, terminal-native.

- Start from semantic tokens, not raw copied colors.
