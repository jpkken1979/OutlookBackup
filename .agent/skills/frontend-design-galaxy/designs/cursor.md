## Vibe

AI-native dark interface with IDE energy, gradient accents, and fast tool ergonomics.

## Best For

- AI coding tools
- operator consoles
- command-heavy products

## Palette Notes

Use deep graphite with restrained gradients in blue-violet ranges for AI emphasis and focus states.

## Typography Notes

Use dense, technical UI typography with monospace support for code and commands.

## Layout Notes

Favor pane-based composition, command areas, and compact controls that still preserve hierarchy.

## Component Notes

Command bars, chat panes, action lists, and file/navigation rails should feel immediate and sharp.

## Remote Excerpt

AI-first code editor. Sleek dark interface, gradient accents.

## Integration Hints

- Start from semantic tokens, not raw copied colors.
- Keep the reference as a direction; adapt it to the product domain.
- Preserve accessibility and interaction clarity over aesthetic mimicry.
