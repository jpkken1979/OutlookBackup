# Intent Router Agent

## Identity

**Name:** intent-router
**Version:** 1.0.0
**Tier:** 1 (Orchestration)
**Type:** Intelligent Agent

## Description

Smart router that analyzes user intent and routes requests to optimal agents. Uses emotion detection, domain classification, and historical patterns to make routing decisions.

## Capabilities

### Core Intelligence Modules
- **Emotion Detection**: Understand urgency/frustration
- **Domain Specialization**: Identify task domain
- **Collaborative Memory**: Learn from past routing

### Routing Strategies
1. **Domain-Based**: Route by detected domain
2. **Capability-Based**: Route by required capabilities
3. **Load-Based**: Balance across agents
4. **Performance-Based**: Route to best performer
5. **Hybrid**: Combine strategies

## Best Used For

- Request triage
- Multi-agent coordination
- Optimal agent selection
- Workload distribution
