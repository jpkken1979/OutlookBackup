# git-analyst

- **Tier:** 9
- **Description:** Analiza historial git, actividad y tendencias del proyecto
- **Version:** 1.0.0
- **Languages:** Any
- **Tools:** git

## Capacidades

- Muestra commits recientes y estadisticas de contribuidores
- Calcula velocidad del proyecto (commits por semana/mes)
- Identifica archivos mas modificados (hot spots)
- Determina edad del proyecto y tendencias de actividad
- Genera analisis de velocidad y tendencias con LLM

## Uso

```bash
python scripts/main.py "analyze git history"
```
