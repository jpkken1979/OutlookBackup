# Regla: Descubrimiento de Skills via skills.sh

Cuando necesites una capacidad que no existe localmente, buscar en skills.sh:

```bash
npx skills find "lo que necesitas"     # Buscar
npx skills add <owner/repo> --skill <name> --agent claude-code --yes  # Instalar
npx skills list                        # Ver instalados
```

Preferir skills con mas instalaciones y de fuentes verificadas.
Siempre revisar el contenido antes de usar.
