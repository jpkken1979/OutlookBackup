# Regla: Sincronización de Memorias

Las memorias del proyecto viven en `.claude/memory/` (dentro del repo) para sincronizarse entre PCs.

Al guardar memorias, escribir en AMBAS ubicaciones:
1. Auto-memory de Claude Code (`~/.claude/projects/...`)
2. Repositorio (`.claude/memory/`)

La ubicación del repositorio es la fuente de verdad.
